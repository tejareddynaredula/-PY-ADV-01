\# Python Employee Management Platform



\## Overview



The Python Employee Management Platform is a mini project that combines Python, Flask, SQLite, Pandas, REST APIs, logging, validation, and unit testing.



\## Features



\- Create employee

\- Update employee

\- Delete employee

\- Search employee

\- List employees

\- Store employee data in SQLite

\- REST API support

\- API request validation

\- Exception handling

\- Application logging

\- Unit testing

\- Employee data analysis using Pandas

\- Basic employee statistics
