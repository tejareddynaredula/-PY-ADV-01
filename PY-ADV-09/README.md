# PY-ADV-09 — Python Data Processing & AI/ML Foundation

## Overview

This project demonstrates Python data-processing fundamentals using NumPy and Pandas.

It also includes an Employee Data Analysis System for cleaning, analyzing, and generating a cleaned employee dataset.

## Technologies

- Python
- NumPy
- Pandas
- Jupyter Notebook
- CSV
